# Product

## Register

product

## Users
BAZ developers inspecting and reusing locally owned components across projects.

## Product Purpose
A standalone, interactive shadcn/ui reference with a reusable monochrome foundation. The Marketing Hub is a separate project.

## Brand Personality
Precise, restrained, seamless. The triangle is BAZ's identity.

## Anti-references
Colored accents, colored state indicators, decorative gradients, and competing theme systems.

## Design Principles
- Keep components locally owned and editable.
- Follow the existing Radix Nova component family consistently.
- Make examples interactive and label simulated data honestly.
- Preserve accessible focus and explicit state descriptions.
- Require rendered visual approval before deployment.

## Accessibility & Inclusion
WCAG AA target, keyboard navigation, visible neutral focus, reduced-motion support, and responsive layouts.
